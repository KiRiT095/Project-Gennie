# Gennie pixel-art assets

`assets/gennie/frames/` contains 16 transparent animation frames extracted from a generated 4×4 pixel-art sprite animation. `gennie_spritesheet.png` is the atlas. `expressions/` contains named reusable poses. `lamp_idle.png` and `lamp_glow.png` are custom pixel-art lamp states. The application uses nearest-neighbour scaling to keep pixel edges crisp.
