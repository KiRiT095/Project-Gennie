# Changelog

## 0.2.0 — Companion UI foundation
- Replaced chat-first startup window with a compact character-first companion.
- Added an expanded conversation/history mode with avatar retained at top.
- Added temporary assistant subtitle and user-transcription display hooks.
- Added state-mapped pixel-art expressions and idle blinking.
- Added compact window dragging, expanded header dragging, Escape-to-compact, and right-click menu.
- Kept audio capture, STT, TTS, wake-word listening, and LLM integration out of this release.
